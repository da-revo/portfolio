[Marketfeed](https://www.marketfeed.com/) is a Y Combinator-backed fintech startup that helps retail investors generate consistent returns from the stock market.

I joined as one of the early Software Engineers and worked directly under the Engineering Lead.

#### Key deliverables

- Helped grow the platform to $16M+ in assets under management
- Drove the adoption of Go, Protocol Buffers, gRPC, and gRPC-Gateway — creating type-safe, language-independent APIs with client library generation, automatic versioning, OpenAPI spec, and documentation generation. Marketfeed now uses Go for all their automated trading infrastructure.
- Designed and implemented multiple features and services on the GCP backend — serverless functions, real-time databases, REST APIs, webhooks, message queues
- Created and shipped a new user onboarding flow with React and Tailwind CSS
- Reviewed code across the engineering team, both junior and senior engineers
- Applied clean code, dependency injection, domain-driven design (DDD), and test-driven development (TDD) across the codebase
